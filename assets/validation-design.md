# Validation 설계

fold를 설계하기 전에 읽는다. 목적은 LB와 순위 상관이 높은 로컬 점수를 만드는 것이다. `folds.npy`가 생성되기 전에는 어떤 학습도 시작하지 않는다.

## 목차

0. 시작 전 확인
1. 데이터 구조별 split 선택
2. Leak 체크리스트
3. Adversarial validation
4. Fold 수와 반복
5. 변동폭 측정

---

## 0. 시작 전 확인

split 선택은 아래 관측에 근거한다. `EDA.md`에서 확인하고, 아직 없으면 지금 확인해
`EDA.md`에 기록한 뒤 진행한다.

- 행(또는 샘플) 단위가 무엇인가
- 같은 개체가 여러 샘플에 걸치는가 (그룹 축 후보). 테이블이면 사용자·매장, 이미지면 촬영 기기·환자·세션, 텍스트면 문서·작성자, 오디오면 화자
- 시간 축이 있는가, test가 train보다 미래인가
- 중복·근사 중복 행이 있는가
- train/test ID 교집합이 있는가
- 타깃 분포와 클래스 불균형 정도

이 중 하나라도 모르는 상태에서 split을 고르면 그 fold는 근거 없이 정해진 것이다.

---

## 1. 데이터 구조별 split 선택

먼저 물어야 할 것은 "test set이 train과 어떤 관계인가"이다. Validation은 그 관계를 로컬에서 모사해야 한다.

| 데이터 구조 | split | 이유 |
|---|---|---|
| 행이 독립, 분류 | `StratifiedKFold` | 클래스 비율 유지로 fold 간 분산 감소 |
| 행이 독립, 회귀 | `KFold` (shuffle=True), 타깃 분포가 치우치면 구간 binning 후 stratify | 극단값이 한 fold에 몰리는 것 방지 |
| 같은 개체가 여러 행 (사용자·환자·매장·이미지 원본) | `StratifiedGroupKFold` | 같은 개체가 train/valid에 동시 존재하면 개체 식별을 학습해 점수가 부풀려짐 |
| 시간 순서가 있고 test가 미래 | `TimeSeriesSplit` 또는 시점 기준 holdout | 미래 정보로 과거를 예측하는 상황을 만들지 않기 위해 |
| 시계열 + 자기상관 강함 (금융 등) | purged K-fold + embargo | 경계 근처 샘플이 상관돼 있어 leak. 경계에서 일정 구간을 버림 |
| 다중 라벨 | `iterative-stratification`의 `MultilabelStratifiedKFold` | 라벨 조합 비율 유지 |
| 소수 클래스가 매우 적음 | `RepeatedStratifiedKFold` | 단일 분할의 분산이 커서 점수가 불안정 |
| train/test가 명시적으로 다른 도메인·기간·지역 | 그 축으로 나눈 leave-one-domain-out | test가 요구하는 일반화를 그대로 측정 |
| 이미지: 같은 촬영 기기·환자·촬영 세션에서 나온 이미지가 여럿 | 그 축 기준 group split | 기기 특성이나 개체를 학습해 점수가 부풀려짐 |
| 텍스트: 같은 문서·작성자·어노테이터에서 나온 문장이 여럿 | 그 축 기준 group split | 문체나 어노테이터 습관을 학습함 |
| 오디오: 같은 화자·녹음 환경 | 화자 기준 group split | 화자 식별로 대체 학습 |

두 가지 구조가 겹칠 때(예: 그룹 + 시간)는 **더 강한 제약을 우선**한다. 그룹과 시간이 모두 있으면 시간으로 자르고 그룹이 경계를 넘지 않게 한다.

### 판단 기준

test set의 ID가 train에 없는 새로운 개체인가? 그렇다면 group split이 필수다. test ID가 train에 등장하는 개체라면 group split은 오히려 과도하게 어려운 검증이 되어 CV가 LB보다 낮게 나온다.

## 2. Leak 체크리스트

fold를 고정하기 전에 전부 확인한다. 하나라도 남기면 CV가 신뢰를 잃는다.
확인 결과는 `EDA.md`의 `leak 후보` 절에 기록한다.

**전처리 위치**

- [ ] scaler, encoder, imputer를 train+test 전체에 fit하지 않았는가 (fold 내부 train에만 fit)
- [ ] target encoding을 fold 내부에서 계산했는가 (전체 데이터로 계산하면 타깃이 새어 나감)
- [ ] 피처 선택을 전체 데이터로 하지 않았는가
- [ ] 결측 대체값을 전체 평균으로 채우지 않았는가

**데이터 자체**

- [ ] 완전 중복 행이 fold를 넘나들지 않는가 (`df.duplicated()` 확인)
- [ ] 근사 중복(같은 이미지의 리사이즈본, 같은 텍스트의 미세 변형)이 없는가
- [ ] ID나 행 순서가 타깃과 상관되지 않는가 (`corr(index, target)` 확인. 상관이 있으면 데이터가 타깃 순으로 정렬된 것)
- [ ] 파일명, 타임스탬프, 파일 크기 같은 메타데이터에 타깃 정보가 들어 있지 않은가
- [ ] 미래 시점에만 알 수 있는 피처가 들어 있지 않은가 (예: 이탈 예측에서 "마지막 접속일")

**집계 피처**

- [ ] 그룹 통계(사용자별 평균 등)를 계산할 때 valid fold의 타깃이 들어가지 않았는가

중복 행 확인은 비용이 거의 없으므로 항상 먼저 한다. 대회 데이터에 중복이 있는 경우는 드물지 않고, 그룹 split 없이 중복이 fold를 넘으면 CV가 크게 부풀려진다.

## 3. Adversarial validation

train과 test의 분포가 다른지 확인하는 절차다. 분포가 다르면 CV-LB 갭의 유력한 원인이 되고, validation 설계 자체를 바꿔야 할 수 있다.

절차:

1. train에 `is_test=0`, test에 `is_test=1` 라벨을 붙이고 합친다.
2. 원래 타깃은 제외하고, 피처만으로 `is_test`를 예측하는 이진 분류기를 학습한다 (LightGBM 등).
3. 이 분류기의 AUC를 본다.

해석:

- AUC ≈ 0.5 → train과 test가 구분되지 않는다. 무작위 split이 타당하다.
- AUC 0.6~0.8 → 부분적 분포 차이. 어떤 피처가 구분에 기여하는지 feature importance로 확인한다. 상위 피처가 ID나 시간 관련이면 그 피처를 제거하거나 시간 기반 split으로 전환한다.
- AUC > 0.9 → 명확한 분포 차이. 무작위 split은 부적절하다. test와 유사한 train 샘플을 valid로 쓰거나(가중 샘플링), test를 닮은 방향의 split을 설계한다.

주의: AUC가 높은 것이 곧 문제인 것은 아니다. 시계열 대회에서 test가 미래면 AUC가 높은 것이 정상이며, 이때 필요한 대응은 "차이 제거"가 아니라 "시간 split 채택"이다.

## 4. Fold 수와 반복

- 기본값은 5-fold다. 데이터가 작아 fold별 valid 크기가 수백 행 수준이면 10-fold를 쓴다.
- fold를 늘리면 편향은 줄지만 학습 시간이 비례해서 늘고, fold 간 상관이 커져 분산 감소 효과는 체감한다. 딥러닝처럼 1 fold에 수십 분 걸리면 5-fold가 현실적이다.
- 실험 초반에는 단일 fold(fold 0)로 빠르게 스크리닝하고, 유망한 설정만 전체 fold로 확인하는 방식이 효율적이다. 단 단일 fold 점수는 ledger에 `cv_mean`이 아니라 별도 필드로 기록하고, 전체 fold 점수와 섞어서 비교하지 않는다.
- 최종 후보 비교에는 시드를 바꾼 반복(repeated CV)을 쓴다. 소수점 셋째 자리 차이를 판정하려면 반복이 필요하다.

## 5. 변동폭 측정

fold 고정과 함께 반드시 수행한다.

1. 베이스라인 설정 하나를 고른다.
2. 시드만 바꿔 3~5회 재실행한다. k-fold를 쓰면 fold 분할 시드와 모델 시드를 모두 바꾸고, 단일 holdout이면 모델 시드만 바꾼다.
3. 결과 점수들의 표준편차를 계산한다. 이것이 **노이즈 하한**이다. 이 값과 측정 방식을 `CLAUDE.md`의 판정 절에 기록한다.

측정 방식은 학습 비용에 따라 다르다. k-fold가 저렴하면 fold 간 분산과 시드 간 분산을 모두 볼 수 있고, 대형 모델이면 동일 설정 3-run의 표준편차 하나로 충분하다. 어느 쪽이든 **하나를 정해 대회 내내 같은 것을 쓴다.** 중간에 바꾸면 앞뒤 판정 기준이 달라진다.

이 값은 판정을 혼자 내리지 않는다. 개선폭이 변동폭보다 크다는 사실 하나로 채택하면 개선폭 0.0025 · 변동폭 0.0021 같은 흔한 경우에서 노이즈를 채택하게 된다. 변동폭은 `CLAUDE.md` 판정 절의 세 신호 중 하나이며, 일관성·분산 변화와 함께 본다. 다만 이 값이 없으면 세 신호 중 하나가 통째로 빠지므로 반드시 측정한다.

시드 재실행이 비쌀 경우(대형 딥러닝 모델) 최소 2회는 수행하고, 표준편차 추정이 불안정하다는 점을 기록한다. 2회도 어려우면 fold 간 표준편차를 대용으로 쓰되, 이것이 데이터 분할 차이만 반영하고 학습 자체의 무작위성은 반영하지 않아 실제보다 작게 나온다는 한계를 함께 적는다.
