# 실험 기록 형식

축 파일(`exp/<축>.md`)의 항목 형식 참조용이다. **규칙은 `CLAUDE.md`에 있다.** 이 파일은 형식만 보여준다.

## 항목 형식

제목: `` ## `<exp_id>` — <바꾼 것 요약> · <판정> ``

필드는 세팅 시 이 대회에 맞게 확정한 것이다. 확정 후 바꾸지 않는다.

```
- 파이프라인:
- 대조:
- 바꾼 것:
- 조건:
- 결과:
- 가설:
- 해석:
```

## 예시

**테이블 · k-fold · AUC** — `exp/feature.md`

```markdown
## `007-target-enc` — target encoding 추가 · 채택

- 파이프라인: `01-lgbm-tabular`
- 대조: `004-lgbm-base`
- 바꾼 것: target_encoding=true (fold 내부 계산)
- 조건: folds.npy, seed=42, 데이터 v1 — 기준과 동일
- 결과: CV 0.8412 ± 0.0037 · fold별 [0.839, 0.845, 0.838, 0.844, 0.840] · LB 0.8351
- 가설: 고카디널리티 범주 정보가 one-hot에서 소실되고 있다.
- 해석: 개선폭 0.0041로 변동폭(0.0021)의 약 2배. fold별 개선이 균일해 특정 fold 의존이 아님.
  LB도 같은 방향으로 이동해 갭 패턴 유지.
```

**이미지 · 단일 holdout · 3-run · mAP** — `exp/augmentation.md`

```markdown
## `012-mosaic-aug` — mosaic 증강 추가 · 진행중

- 파이프라인: `02-yolo-detect`
- 대조: `009-baseline-aug` (mAP 0.608 ± 0.006, run별 0.602 / 0.611 / 0.611)
- 바꾼 것: mosaic p=0.5 추가
- 조건: holdout(촬영 세션 단위 분할), 3 run (seed 0/1/2), 60 epoch, 입력 640
- 결과: val mAP@0.5 0.615 ± 0.011 (run별 0.603 / 0.621 / 0.621) · best epoch 평균 47
- 가설: 소객체 검출이 배경 다양성 부족으로 약하다.
- 해석: 신호가 엇갈림. 개선폭 0.007로 변동폭(0.006) 바로 위, 일관성은 3 run 중 2 run만
  개선(하락한 run은 없음), 분산은 0.006 → 0.011로 확대. best epoch가 뒤로 밀려
  60 epoch에서 잘린 가능성 있음. 판정을 가를 축: 학습 곡선과 소객체 AP.
  전자는 기존 로그로 확인 가능, 후자는 재평가 5분.
```

필드 이름은 같지만 `조건`과 `결과`에 담기는 것이 유형에 따라 다르다. 두 예시 모두 세 신호(개선폭 대 변동폭, 일관성, 분산 변화)가 `결과`에서 읽힌다.

## 축 파일 머리말

축 파일은 아래 세 줄로 시작한다. 규칙을 다시 쓰지 않는다.

```markdown
# <축 이름> 실험 기록

<이 축이 무엇을 바꾸는 실험인지 한 줄>. 규칙은 `CLAUDE.md`, 형식은 `exp/TEMPLATE.md`.
```
